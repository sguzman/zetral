# LXX: independent check of the 47/4 endpoint witness

## Exact endpoint

The rational endpoint is `47/4 = 8(47/32)`. Using the positive atanh series
for `log(2)` and `log(47/32)` gives a rational lower bound
`log(47/4)-2.46 > 3853240590167/10^15`. Thus `exp(2.46) < 47/4` follows
without a floating-point endpoint comparison.

## Piecewise witness

The proposal file
`experiments/results/lxx-47-4-rational-witness.json` was generated by the
existing exact rational witness optimizer at refinement step 16. A separate
Python `Fraction` verifier reconstructed the one-step refinement of all
stored partition endpoints under the eight shifts, evaluated each rational
cell midpoint, and checked the integer inequality on every refined cell. It
verified 55,613 cells and all 40,933 stored intervals, with worst rounded
ratio exactly `2897/1000`. The checker independently verifies the eight
shift-coefficient upper bounds using rational log-series upper bounds and
integer-square-root lower bounds. The optimizer proposal is not independently
reimplemented; the certificate inequality is independently checked.

## High-mode guards

Using `C=2897/1000` in the campaign's even/odd high-weight guards, exact
rational lower estimates give:

- Even, `lowCount=45`, first omitted mode `n=90`: guard exceeds
  `9387592552/10^12`.
- Odd, `lowCount=45`, first omitted mode `n=91`: guard exceeds
  `20439511307/10^12`.

The logarithm lower bounds use the positive atanh series; the correction and
odd pole-loss terms use rational upper bounds, including a Taylor upper bound
for `cosh(2.46/4)` and a Machin-series lower bound for pi. For fixed
lowCount, the guard increases with n, since its logarithmic term increases
and the inverse-square correction decreases. The odd pole-loss term is
constant in n. Hence these first omitted-mode bounds imply positivity for all
subsequent modes in the corresponding parity.

Reproduce the independent checks with:

```sh
python3 experiments/worker-LXX/verify_47_4_witness.py
```

The proposal can be regenerated with:

```sh
node experiments/worker-LXX/propose_47_4.js > /tmp/lxx-47-4-witness.json
```

This only validates the endpoint witness and guards. It does not establish
either sector's finite comparison, the h=2.46 candidate frontier, or a
Hilbert–Pólya operator result.
